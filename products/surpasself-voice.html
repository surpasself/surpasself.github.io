PWA Markdown MCP Local-first

Problem

人在说话时，想法经常是乱的。

真实口述会包含停顿、语气词、重复、跳跃和临时补充。产品的价值不是简单转文字，而是把口述转成可以继续工作的结构：背景、目标、需求、任务、风险和下一步。

第一版先保证本地记录和 Markdown 编辑，后续再把智能整理升级为可选择模型、个人 API Key、云中继和工作流模板。

Architecture

公开页面只讲产品，不公开源码。

GitHub Pages 只承载静态介绍和浏览器前端成品；同步、模型调用、OAuth、MCP 等能力需要独立后端或本地伴侣服务。

Frontend

React + TypeScript/PWA 方向。GitHub Pages 版本可直接打开、录音、编辑和本地保存。

Local data

IndexedDB 和本机 Markdown 镜像。敏感内容优先留在用户设备上。

Relay

跨设备实时同步、手机扫码、MCP 写入需要 HTTPS/WSS 中继，后续可用 Cloudflare Workers 或 Supabase。

重要边界：公开网页版本会暴露前端打包后的浏览器代码，这是所有静态 Web App 的正常限制；MCP、本地数据、私有文档、密钥和后端能力不会放入公开 Pages 仓库。

Business model

收费点压在跨设备、工作流和效率。

基础记录不打扰用户，付费围绕更高频、更省时间、更能沉淀项目的能力。
